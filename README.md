# 健身菜單（雙分化雙循環）

## ▶ [點這裡開啟健身菜單](https://TYwry.github.io/workout-menu/)

（iPhone Safari 開啟後，點「分享」→「加入主畫面」）

---

iPhone Safari 用的單頁健身菜單。

- 主畫面：本週日期（週一到週日）可打勾並標註「胸肩背組／上下肢組」；下方表格顯示今天那組的動作、重量、次數、組數。
- 右上月曆圖示：歷史紀錄，用月曆看過去每週練了幾次、練哪一組，也可補登或修改。
- 右上齒輪進入設定：調整重量（引體向上、坐姿划船每次 ±1 kg，其他 ±2.5 kg）、次數（6/8/10/12）、組數（3/4）。
- 所有資料自動存在手機上；打勾紀錄保留約 2 年，更舊的自動清除。

## 使用
1. 第一次：雙擊 `setup-github.bat`（會安裝 Git／GitHub CLI、登入、建立儲存庫並開啟 GitHub Pages）。
2. 點本頁最上方的連結，用 iPhone Safari 開啟 → 分享 →「加入主畫面」。
3. 之後修改檔案：雙擊 `save.bat` 上傳。

## 注意
- 資料只存在這支手機的瀏覽器（localStorage），不會上傳。換手機或清除 Safari 網站資料會回到預設值。
- 請從「主畫面圖示」開啟；只用 Safari 分頁開、且超過 7 天沒開時，Safari 可能清掉資料。
- GitHub Pages 免費方案需公開儲存庫，網址任何人都能看到菜單內容（不含個資、訓練紀錄）。
