# 健身菜單（雙分化雙循環）

一個給 iPhone 用的健身菜單 App（從網頁加到主畫面使用）：打開就知道今天要練哪些動作、用多重、做幾下幾組，練完可以記錄實際做了多少、寫下心得，也能回頭看過去幾週的訓練次數、筆記和體重變化。

## 🌐 [點這裡直接開啟健身菜單](https://iphone-sport.web.app/)

不用下載、不用安裝。用 iPhone 的 Safari 開啟上面的連結，再點「分享」→「加入主畫面」，就能像 App 一樣從主畫面全螢幕打開。

> **以前用舊網址（`github.io` 開頭）的人**：舊網址已經改成「搬家通知」頁，打開後按「匯出舊資料」，再到新網址「匯入」就能把紀錄搬過來，步驟見下方「從舊網址搬過來」。

## 這個網頁能做什麼

- **今天練什麼一目了然**：分成「胸肩背組」和「上下肢組」兩組，點上方按鈕切換。下方表格列出每個動作的重量、次數、組數。
- **本週打勾**：畫面上方顯示這週一到週日，練過的日子會打勾並標出練了哪一組，右上角顯示「已練 幾 / 4 次」。
- **記錄實際做了多少**：練完按「今天練完了，記錄並打勾」，每一組的重量和次數都已照計畫填好；哪一組少做或多做，用 − ＋ 改掉就好（例如第 3 組只做了 7 下）。也可以多加一組、刪掉一組，或把沒做的動作整個刪掉。
- **心得與筆記**：練完時可以在紀錄頁最下面寫「今日心得」；沒練的日子也能點那天寫筆記（例如「休息日，腿還有點痠」）。有筆記的日子在日期上會有一個小點，點進去就能讀到完整內容。
- **每週練滿 4 次的鼓勵**：這週存下第 4 次紀錄時，會有一隻可愛的機器人跳出來跳舞為你加油，按「繼續」關閉。每週只會出現一次。
- **每週體重**：每週第一次練完時會提醒你量體重；也可以隨時點「本週體重」輸入或修改。
- **歷史紀錄**：用月曆看每天練了哪一組、哪幾天有筆記、每週練了幾次、每個月的總次數，以及每週的體重和跟前一週的差距。點月曆上的任一天，可以查看、補登或修改那天的紀錄和筆記。
- **調整計畫**：點右上角齒輪，可以改每個動作的預定重量、次數、組數。
- **資料備份（匯出／匯入）**：在設定頁最下面，可以把所有紀錄匯出成一個備份檔，換手機或換開啟方式時再匯入，紀錄就不會不見。

## 使用前需要準備什麼

- 一支 iPhone，使用內建的 **Safari** 瀏覽器（其他手機或電腦的瀏覽器也能開，但畫面是照 iPhone 設計的）。
- 第一次打開需要網路；之後 App 會存一份在手機上，沒有網路也能打開、記錄。
- 不用註冊帳號，也不用安裝任何東西。

## 怎麼開始使用

1. 在 iPhone 上用 Safari 點開本頁最上方的「點這裡直接開啟健身菜單」。
2. 點畫面下方的「分享」按鈕（方框加向上箭頭的圖示）。
3. 往下找到「加入主畫面」，點「新增」。
4. 之後從主畫面的「健身菜單」圖示打開即可。
5. 第一次使用時，建議先點右上角 **齒輪**，把每個動作的重量、次數、組數改成你自己的計畫，改完按「完成」。

### 每次練完之後

1. 在主畫面點上方的「胸肩背組」或「上下肢組」，選今天練的那一組。
2. 練完按最下面的「今天練完了，記錄並打勾」。
3. 在紀錄頁把實際做的重量、次數改好（跟計畫一樣就不用改）；想記下感受的話，在最下面的「今日心得」寫幾句（可以不寫）。
4. 按「儲存並打勾」。
5. 如果是這週第一次練，會跳出體重輸入框，輸入體重（例如 70.5）後按「儲存」；不想記可以按「稍後再說」。
6. 如果是這週第 4 次，機器人會跳出來鼓勵你，按「繼續」即可。

### 沒練的日子想寫筆記

點本週日期（或歷史紀錄月曆）上的那一天 →「寫筆記」→ 寫完按「儲存」。要修改時點「編輯筆記」；把內容清空或按「刪除這則筆記」就會刪除。

### 從舊網址搬過來

健身菜單原本放在 `github.io` 開頭的網址，現在搬到上方的新網址。手機的紀錄是**依網址分開存的**，所以要手動搬一次：

1. 用原本的方式（主畫面舊圖示或 Safari）打開舊網址，會看到「健身菜單搬家了」。
2. 如果舊網址還有紀錄，頁面會顯示有幾天紀錄、幾週體重、幾則筆記。按「匯出舊資料」，選「儲存到檔案」（或用 AirDrop、LINE 傳給自己）。
3. 按「打開新的健身菜單」，照上方「怎麼開始使用」把新網址加入主畫面。
4. 在新的健身菜單點右上角齒輪 → 最下面「資料備份」→「從檔案匯入」，選剛剛的檔案，再選「合併」。
5. 確認新網址看得到以前的紀錄後，就可以把主畫面上的舊圖示移除。

舊網址的紀錄不會因為匯出而刪除，搬失敗可以再匯出一次。

### 網頁更新時，紀錄會不見嗎？

**不會。** 只要網址不變，網頁更新後打開就是新的畫面，原本的紀錄全部都在，不用做任何事。

- 打開網頁時只會讀取資料，不會改寫；你實際操作（打勾、改重量、寫筆記等）時才會存檔。
- 新版看不懂的資料會原封不動保留，不會被刪掉。
- 每天第一次打開時，會自動在手機裡保留一份「到前一天為止」的資料。萬一更新後資料有問題，可以到設定頁最下面按「還原到昨天的自動備份」。
- 設定頁最下面會顯示目前的版本，可以用來確認是不是已經換成新版。App 會在背景自動下載新版，下次**完全關掉再打開**（從多工畫面滑掉）就會換成新版，畫面下方會提示「已更新到新版本」。

### 備份資料、搬到新手機或新的開啟方式

所有紀錄都只存在手機的瀏覽器裡，而且是**依網址分開存的**。以下情況，舊的紀錄**不會自動跟過去**，請先備份再搬：

- 換新手機，或要清除 Safari 的網站資料
- 原本用 Safari 分頁開啟，後來改成「加入主畫面」的圖示開啟（iPhone 上兩者的資料是分開存的）
- 網頁的網址改變（例如從舊的 `github.io` 網址換到新網址）

**匯出（在舊的地方做）**
1. 打開健身菜單 → 點右上角齒輪 → 捲到最下面的「資料備份」。
2. 點「匯出備份」。iPhone 會跳出分享選單，選「儲存到檔案」存到 iCloud 雲碟或「我的 iPhone」，或用 AirDrop、LINE 傳給自己。
   - 備份檔名像這樣：`workout-menu-backup-2026-10-04.json`（最後是匯出日期）。
   - 也可以點「複製備份文字」，把內容貼到備忘錄或 LINE 保存。

**匯入（在新的地方做）**
1. 打開健身菜單 → 點右上角齒輪 → 捲到最下面的「資料備份」。
2. 點「從檔案匯入」選擇剛剛的備份檔；或點「貼上備份文字匯入」，把複製的內容整段貼上。
3. 畫面會先顯示備份裡有幾天紀錄、幾週體重、幾則筆記，再選擇：
   - **合併（建議）**：只加入這裡沒有的日子；同一天兩邊都有資料時，保留這裡現有的。
   - **全部取代**：整個換成備份的內容（包含計畫的重量、次數、組數），會再確認一次。
4. 完成後畫面下方會顯示匯入了多少資料。

備份檔有問題（例如不是這個網頁的備份、內容不完整）時，會說明原因，**現有的資料不會被動到**。

## 檔案說明

一般使用者**不需要下載任何檔案**，直接用上面的連結即可。以下是給想自己架設或修改的人參考：

| 檔案 | 用途 |
|---|---|
| `public/index.html` | App 本體，所有功能都在這個檔案裡。 |
| `public/sw.js` | 讓 App 沒網路也能打開、並在背景自動更新的小程式（只管畫面檔案，不碰你的紀錄）。 |
| `public/manifest.json`、`public/icons/` | 加到主畫面時的名稱與圖示。 |
| `firebase.json`、`.firebaserc` | Firebase 架站設定；`.firebaserc` 裡是要部署到哪個 Firebase 專案。 |
| `setup-firebase.bat` | （Windows）第一次部署前執行一次：安裝 Node.js、Firebase 工具並登入 Google 帳號。 |
| `deploy.bat` | （Windows）把 `public/` 部署到 Firebase。每次修改後雙擊，手機下次打開就會換成新版。 |
| `scripts/bump-version.js` | 部署時自動更新版本號，由 `deploy.bat` 呼叫，不用自己執行。 |
| `index.html`、`apple-touch-icon.png` | 舊網址的「搬家通知」頁，可以把舊紀錄匯出。 |
| `screenshots/` | 本說明頁使用的畫面截圖。 |
| `setup-github.bat`、`save.bat` | （Windows）把專案存到 GitHub；`setup-github.bat` 只在第一次執行，之後每次存檔用 `save.bat`。 |

### 想自己架一份

1. 下載本專案：在 GitHub 頁面按綠色「Code」→「Download ZIP」，解壓縮到任一資料夾。
2. 雙擊 `setup-firebase.bat`，照畫面指示安裝並登入 Google 帳號（只要做一次）。
3. 到 [Firebase 控制台](https://console.firebase.google.com) 建立一個專案（免費方案即可），記下「專案 ID」。
4. 用記事本打開 `.firebaserc`，把裡面的 `iphone-sport` 換成你的專案 ID，存檔。
5. 雙擊 `deploy.bat`。完成後網址是 `https://你的專案ID.web.app`。

## 常見問題

**Q：換了手機，或清除 Safari 的網站資料後，紀錄不見了？**
所有資料只存在這支手機的瀏覽器裡，沒有自動備份到網路上，所以換手機或清除網站資料後會回到預設值。請事先用設定頁的「匯出備份」存一份，之後再「匯入」就能找回（見上方「備份資料、搬到新手機或新的開啟方式」）。

**Q：加到主畫面後，原本在 Safari 記的紀錄不見了？**
iPhone 上「Safari 分頁」和「主畫面圖示」的資料是分開存的。請在 Safari 分頁打開健身菜單「匯出備份」，再到主畫面圖示打開的健身菜單「匯入」。

**Q：網頁更新後，資料看起來怪怪的或不見了怎麼辦？**
到設定頁最下面按「還原到昨天的自動備份」，可以回到前一天為止的資料（還原前會再確認一次，目前的資料也會另外保留一份）。

**Q：畫面下方出現「讀取資料時發現問題，原始資料已另外保留」？**
代表手機裡存的資料有損壞。網頁不會把原本的資料蓋掉，會另外保留一份。可以先試試「還原到昨天的自動備份」，或用之前匯出的備份檔匯入。

**Q：隔了一陣子沒打開，資料不見了？**
請從「主畫面圖示」打開。如果只是用 Safari 分頁開啟，且超過 7 天沒有使用，Safari 可能會自動清掉網站資料。

**Q：頁面最下面出現「此瀏覽器無法儲存資料」？**
代表瀏覽器不允許這個網頁存資料（例如使用「私密瀏覽」）。請改用一般模式的 Safari 開啟。

**Q：怎麼刪除某一天的訓練紀錄？會把筆記也刪掉嗎？**
點那一天 →「沒有練（清除）」，會先跳出「確定要刪除訓練紀錄嗎？」的確認視窗，按「確定刪除」才會真的刪除，按「取消」則不會有任何變動。清除只會拿掉那天的打勾和組數紀錄，筆記會保留；要刪筆記請用「編輯筆記」→「刪除這則筆記」。

**Q：打開舊網址只看到「健身菜單搬家了」？**
健身菜單換到新網址了，請按「打開新的健身菜單」。舊網址有紀錄的話，先按「匯出舊資料」，再到新網址匯入（見上方「從舊網址搬過來」）。

**Q：動作的名稱可以改嗎？**
目前動作名稱是固定的，只能調整重量、次數、組數。

## 注意事項

- **資料只存在你的手機上**：訓練紀錄、筆記、體重都存在手機的瀏覽器裡，不會傳到任何伺服器。App 只會連到自己的網址下載新版畫面，不會連線到其他網站。
- **備份檔請自己保管**：備份檔裡有你的訓練紀錄、體重和筆記，請存在自己的地方，不要傳給不認識的人。
- **自動清除舊資料**：打勾紀錄、詳細紀錄、筆記和體重會保留約 2 年，更舊的會自動刪除。
- **網頁內容是公開的**：App 放在 Firebase 網站上，任何人都能打開這個網址看到預設的菜單；但每個人的紀錄都只存在自己的手機裡，別人看不到。
